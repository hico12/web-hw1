# 웹개발기초 실습과제 #1 — 영화 보드

## 사이트 구성
- `index.html`: 내가 고른 영화 5편과 일별 박스오피스 TOP 5 섹션
- `detail.html`: 극한직업 상세 페이지
- `style.css`: 공통 스타일, CSS 변수, 반응형 레이아웃

## 데이터 출처
- 영화 포스터 및 영화 정보: [TMDB](https://www.themoviedb.org/)
- 일별 박스오피스 공식 출처: [영화관입장권통합전산망(KOBIS)](https://www.kobis.or.kr/kobis/business/main/main.do)

## 제출 전 반드시 확인할 사항
1. `index.html`의 박스오피스 TOP 5 카드에 KOBIS 공식 일별 조회 결과를 입력한다.
2. 기준 날짜, 순위, 영화명, 개봉 연도, 관객 수/순위 변동을 공식 자료와 대조한다.
3. KOBIS 결과에 맞는 포스터 URL을 넣는다.
4. 브라우저에서 360px, 768px, 1280px 화면을 확인하고 각각 `w360.png`, `w768.png`, `w1280.png`로 캡처한다.
5. GitHub Pages에 배포한 뒤 `index.html`과 `detail.html` 링크가 정상 작동하는지 확인한다.

수업 및 교수님의 지침에 맞게 실제로 사용한 AI 도움의 내용과 반영 여부를 직접 기록한다.
